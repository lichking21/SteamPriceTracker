# SteamPriceTracker

An automation tool designed to help users track and get notified about games price changes on the Steam Store.

### Key Features
* **Real-time Monitoring:** Fetch the latest price data directly from the Steam API.
* **Custom Alerts:** Set price thresholds and receive instant notifications (via Telegram/Discord/Email).
* **Historical Data:** Track price trends over time.
* **Multi-Currency Support:** View prices in your preferred local currency.
* **User-Friendly Configuration:** Easy setup via JSON or environment variables.

### Tech Stack
* **Language:** C#
* **Libraries:** EntityFrameworkCore, Telegram.Bot
* **Database:** PostgreSQL
